# IdleScape (Java)

IdleScape is an Old School RuneScape inspired idle game, akin to Melvor idle.

I have been a Unity developer professionally for the last 5 years. Most of the development work I have contributed to has been in or adjacent to the Unity engine

This project is a means for me to gain experience outside of engines and focus more on the fundamentals whilst sticking with something familiar. 

This is my first project in Java and my first time using Gradle outside a game engine.

## Features

In this repo, I intend to get the underlying systems built to house this idle game including:

- Tick system
- Player character
  - Skills
  - Inventory 
- Rendering
- Networking
